# Project scope

## WILL

- Collect and normalise logs from Linux, web servers, Windows, firewall syslog, and physical sensors.
- Define YAML detection rules for thresholds, correlations, and baseline deviations, mapped to MITRE ATT&CK.
- Provide alerts, cases, timelines, notes, and incident report export.
- Provide role-based access control (RBAC) and an audit log.
- Monitor the health of the service itself.
- Include tests, CI, and Docker deployment.
- Report measured results from real attack simulations.

## WILL NOT

- Use machine learning.
- Automate response through SOAR.
- Support multi-tenancy.
- Claim production readiness.
- Support every device or log format.
